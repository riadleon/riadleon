Current research
ImmunoDefense: Merging Computational Immunology with Reinforcement Learning toward Autonomous Cyber-Physical System Protection
I'm developing an artificial immune, negative-selection approach to anomaly detection in ICS/SCADA systems. My main experimental dataset is HAI 23.05.
The planned response stage uses reinforcement learning with a safety filter and human override. Its proposed actions are Observe, Alert, Rate-limit, and Temporary Isolation. GRFICSv3 is the selected environment for later controlled response experiments.
This is ongoing research. I am working on reproducible experiments, clear evaluation, and a prototype that can be demonstrated and explained.
